# ADR-013 — Precio base, precio mensual y saldo Asesor

## Estado

Aceptada — 2026-09-01

## Contexto

Programación exponía tres representaciones vinculadas del descuento y llamaba Precio base al valor mensual. Esto confundía el precio de catálogo de Productos, el descuento ya incorporado y el dinero que todavía podía conceder el asesor.

## Decisión

1. `productos.list_price_mxn` es el Precio base y se muestra como referencia fija.
2. `crm_precios_mensuales.precio` es el Precio del mes.
3. La interfaz captura `asesor_dinero` como saldo adicional independiente.
4. El servidor deriva el descuento incorporado como base menos mensual y el tope acumulado como incorporado más Asesor.
5. Las columnas históricas `promo_dinero`, `promo_porcentaje` y `tope_descuento_mxn` permanecen como representación persistida compatible.
6. Cotizador muestra el Precio base y representa en la barra el descuento acumulado desde el descuento incorporado hasta incorporado más Asesor.

## Consecuencias

- Se elimina la captura redundante de porcentaje; el descuento mensual en dinero permanece vinculado al precio del mes.
- El saldo Asesor puede aumentarse o reducirse explícitamente por mes.
- No se requiere una migración destructiva ni se recalculan cotizaciones históricas.
