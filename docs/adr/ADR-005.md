# ADR-005 — Remediación de dependencias vulnerables

- Estado: implementado localmente en `CHG-005`
- Fecha: 2026-07-27

## Contexto

`npm audit --omit=dev` encontró vulnerabilidades en `body-parser`, `tar` y `undici`, incluidas severidades crítica y alta.

## Decisión

Aplicar las versiones transitivas corregidas propuestas por npm, conservar las dependencias directas actuales y validar auditoría, suite funcional, sintaxis y trazabilidad estricta.

## Consecuencias

- El lockfile cambia de forma intencional.
- No se declara seguridad permanente: nuevas divulgaciones requieren repetir la auditoría.
- No se realiza despliegue ni publicación.
