# ADR-011 — Tope mensual completo en Cotizador

- Estado: aprobado para implementación en `CHG-011`
- Fecha: 2026-09-01
- Aprobación: responsable de producto mediante imagen y aclaración del flujo esperado

## Contexto

El Cotizador restaba del tope mensual la diferencia entre catálogo y precio de Programación. Esto reducía la barra por debajo del límite que el responsable comercial configuró para el mes.

## Decisión

- El precio inicial del Cotizador es el precio mensual de Programación.
- El rango manual va de cero al tope promocional completo configurado para ese mes.
- La diferencia frente al catálogo se conserva como información auditable, pero no consume la barra.
- El máximo efectivo nunca supera el precio neto previo al descuento manual.
- El servidor valida el mismo límite en previsualización, creación y edición; el navegador no es autoridad.
- Esta decisión sustituye la resta del descuento mensual embebido definida en ADR-009, sin cambiar la fuente del precio mensual ni el snapshot histórico.

## Consecuencias

- Con precio mensual `6,300` y tope `1,089`, el asesor puede llegar a `5,211`.
- La barra muestra el límite mensual completo y el importe aplicado en tiempo real.
- Cotizaciones históricas permanecen sin recalcularse.
