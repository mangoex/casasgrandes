# ADR-007 — Unidad transaccional comercial

- Estado: implementado localmente en `CHG-007`
- Fecha: 2026-07-27

## Decisión

- Creación y edición de cotización usan `db.transaction`.
- Planificación, prospecto, cotización y productos se bloquean antes de revalidar estado o saldo.
- Los productos se bloquean en orden numérico estable.
- Errores de carrera producen conflicto y cualquier fallo posterior ejecuta rollback.

## Consecuencias

- La cotización original permanece íntegra si falla una edición.
- Una conversión repetida devuelve el prospecto existente.
- El alcance local demuestra el protocolo; concurrencia real requiere PostgreSQL aislado.
