# ADR-001 — Sesión web en cookie HttpOnly

- Estado: aprobado para `CHG-001`
- Fecha: 2026-07-26

## Contexto

El JWT estaba disponible para cualquier JavaScript mediante `localStorage`. Una inyección XSS podía extraerlo y reutilizarlo durante siete días.

## Decisión

El navegador usará una cookie `auth_token` con `HttpOnly`, `SameSite=Strict`, ruta `/` y `Secure` cuando `NODE_ENV=production`. El middleware conservará compatibilidad temporal con Bearer para verificadores internos.

## Alternativas descartadas

- Mantener `localStorage`: conserva el impacto de robo de token.
- `sessionStorage`: sigue siendo legible por JavaScript.
- Cookie sin `HttpOnly`: no reduce el impacto principal.

## Consecuencias

- El frontend restaura sesión con `/api/auth/me`.
- Logout requiere endpoint servidor para invalidar la cookie del navegador.
- El control CSRF se apoya en `SameSite=Strict` y origen único; cualquier futura integración cross-site deberá diseñarse explícitamente.
