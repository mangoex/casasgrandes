# ADR-015 — Descuento de Cuenta Clave exclusivo para semillas

## Estado

Aceptada — 2026-09-03
Cambio: CHG-017

## Contexto

El nivel comercial de Cuenta Clave (ej. Adquirir, Desarrollar, Retener, Retener GOLD) confiere un descuento fijo en MXN por unidad. En la implementación previa, este descuento se descontaba de forma incondicional al calcular el precio neto de cualquier producto tras aplicar su precio de temporada o catálogo, afectando indebidamente a productos de la categoría Agroquímicos (ej. Clavis, Faena) y Fertilizantes.

La intención comercial original de la empresa establece que el beneficio de Cuenta Clave no aplica a todas las semillas, sino exclusivamente a dos productos: **Calamar** e **Hipopótamo** (`Híbrido` o `Semilla`). Quedan excluidas otras variedades de semillas (como Rinoceronte, Armadillo, Vitala, A-7573) y todos los productos químicos o fertilizantes.

## Decisión

1. El descuento por Cuenta Clave (`descuento_cuenta_clave_mxn`) solo es elegible para productos cuya categoría sea `Híbrido` o `Semilla` Y cuyo nombre corresponda a **Calamar** o **Hipopótamo** (insensible a mayúsculas y acentos).
2. Para cualquier otro producto (incluyendo otras semillas, híbridos, agroquímicos y fertilizantes), el descuento de Cuenta Clave es exactamente `$0.00 MXN`.
3. El oráculo determinista en Python (`pricing_reference.py`, `cotizador.py`) define la función canónica de elegibilidad y cálculo de precios netos.
4. El motor en JavaScript (`utils/pricing.js`) sincroniza idéntica regla mediante `isKeyAccountEligible(prod)`.
5. Cuando una partida no sea elegible para Cuenta Clave, la interfaz de Cotizador no muestra el bloque visual de Cuenta Clave y su precio neto no sufre deducción.

## Consecuencias

- Únicamente Calamar e Hipopótamo reciben el beneficio comercial de Cuenta Clave.
- Los agroquímicos, fertilizantes y otras semillas conservan su precio de catálogo/temporada exacto sin subsidio de Cuenta Clave.
- Se mantiene consistencia estricta entre el oráculo en Python y el runtime de producción en Node.js.
