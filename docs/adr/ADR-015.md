# ADR-015 — Descuento de Cuenta Clave exclusivo para semillas

## Estado

Aceptada — 2026-09-03
Cambio: CHG-017

## Contexto

El nivel comercial de Cuenta Clave (ej. Adquirir, Desarrollar, Retener, Retener GOLD) confiere un descuento fijo en MXN por unidad. En la implementación previa, este descuento se descontaba de forma incondicional al calcular el precio neto de cualquier producto tras aplicar su precio de temporada o catálogo, afectando indebidamente a productos de la categoría Agroquímicos (ej. Clavis, Faena) y Fertilizantes.

La intención comercial original de la empresa establece que el beneficio de Cuenta Clave es exclusivo para semillas (categorías `Híbrido` y `Semilla`, como Hipopótamo y Calamar), y no debe aplicarse a productos químicos ni fertilizantes.

## Decisión

1. El descuento por Cuenta Clave (`descuento_cuenta_clave_mxn`) solo es elegible para productos cuya categoría sea `Híbrido` o `Semilla`.
2. Para cualquier otra categoría (incluyendo `Agroquímico` y `Fertilizante`), el descuento de Cuenta Clave es exactamente `$0.00 MXN`.
3. El oráculo determinista en Python (`pricing_reference.py`) define la función canónica de elegibilidad y cálculo de precios netos.
4. El motor en JavaScript (`utils/pricing.js`) sincroniza idéntica regla mediante `isKeyAccountEligible(prod)`.
5. Cuando una partida no sea elegible para Cuenta Clave, la interfaz de Cotizador no muestra el bloque visual de Cuenta Clave y su precio neto no sufre deducción.

## Consecuencias

- Los agroquímicos conservan su precio de catálogo/temporada exacto sin subsidio de Cuenta Clave.
- No se requiere migración de esquema en la base de datos; la regla es determinista a nivel de motor de precios.
- Se mantiene consistencia estricta entre el oráculo en Python y el runtime de producción en Node.js.
