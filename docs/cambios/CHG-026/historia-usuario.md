# Historia de usuario — CHG-026

- ID: CHG-026
- Fecha: 2026-11-03
- Actor: propietario del producto y agentes de código
- Estado: propuesta

Como propietario, quiero que cada cambio futuro recorra historia, requisito, contrato, criterios de aceptación, pruebas primero, implementación y CI, para poder revisar un pull request sin descubrir el alcance en el código.

## Fuera de alcance

- No agrega endpoints, pantallas, columnas ni reglas comerciales.
- No implementa `/api/v1/bot`.
- No borra los CSV ni reescribe el historial de git.
- No hace merge ni despliegue.
